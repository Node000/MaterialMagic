# 当前游戏规则

本页按 2026-11-05 现有代码与配置记录当前行为，不沿用旧方案默认值；不代表已做运行验收。未实现功能见 `Assets/Docs/Workflow/KNOWN_GAPS.md`。

## 开局与核心循环

- 主菜单开始新局选择 StartConfig，继续使用所选槽位运行档；教程为可重复的临时运行。
- StartConfig.json 当前有 balanced、ice_fire、wind_dust、blank 四套。均抽 4、起始金币 2、出牌上限 8；前三套生命 50，blank 45。牌组和初始道具以各配置为准。
- 默认 balanced 为四元素各 4 张，初始道具 numericId 2、14、26。当前不是“起始抽5/最多打3/没有素材基础效果”的旧版本。
- 枚举/方向：Fire=1=上，Wind=2=左，Water=3=下，Earth=4=右，Wild=5。素材进入读取序列后，基础效果与道具匹配一起结算。
- 当前基础效果：上对锁定敌人主动攻击 3；下对目标加虚弱1和易损1；左给玩家额外抽牌1；右获得护盾3。附魔、Buff、进阶和基础强化可能修正行为。
- 每回合额度在从手牌移入出牌区时计费；回手退还已计费牌额度；换牌不额外扣/退额度。特殊附魔可禁用、绕过额度或改变读取。
- 道具按连续 Token 配方匹配，同一起点按道具布局/槽位顺序处理，不按配方长短排序；可在不同起点或重读序列重复触发。

## 地图与节点

- 普通章节1配置 5×8、初始(2,0)、levelLength=18；RunManager 管章节池、地图位置、Boss 缓存和进度，进阶会改宽高/步数/阻挡等。
- 方向移动不环绕，不能进入不可用格；消耗普通格后保留底图，图标/内容状态由地图模型和 UI 刷新。
- 战斗/精英胜利通常先自动基础金币，再展示金币/单件道具/单只箭头，选择一个或跳过，接自动商店。基础自动金币基数2并走进阶倍率；额外金币选项从现行经济配置按关卡类别取值，不承诺等于基础金币。
- 商店默认一个道具层与一个箭头层；预算6、道具占2、箭头占1.5，通常3道具+4箭头，箭头末格保底强附魔。价格见经济模块。
- 事件用首序列 Token 匹配配方字符串；选项 effects 决定即时/延后效果及后继节点。休息复用事件面板。
- 离开节点回地图强制清空战斗手牌与出牌区，保留类效果不能让旧战斗箭头留在地图阶段。

## 成长与存档

- 进阶支持正阶与负阶，DifficultyUpgradeSystem 按所选方向累计 upgradeIds。数据和 UI 解锁由当前 Ascension/Unlock 配置决定。
- 解锁进度与运行档独立；正常结算收口处理；教程不写普通档、历史、解锁结算。
- 运行档有3槽、每槽独立历史最多100条；当前版本4，含遗物状态/pending候选与玩家Buff运行态；按检查点保存，不是每次操作即时存档。
- 箭头基础强化有四方向页和本体节点、SO数值与保存字段；正式一层到二层流程尚未接入。

## 教程与服务

- 教程章节100为1×5，内容为战斗1001、事件1002、休息201、Boss1005；没有单独商店格，战后自动商店仍可出现。
- 教程起始金币10，前两回合固定手牌和换牌演示；步骤按 TutorialManagerUI 驱动，阅读段落与行为页有输入门控。
- TapTap/统计是可选启动分支：先询问同意；拒绝不初始化 TapSDK、不登录，但可游玩；同意后等待初始化成功再自动登录。设置可更改采集选择。

## 不列为当前玩法

遗物已有可测试逻辑层，但未向正常流程投放且无UI/二层门控；其投放、故障值/Tag 过渡商店、自动进入二层、第一人称探索接主流程均不是现行常规循环。独立原型和保留枚举不等于已接入功能。历史设计已从活动知识移出，保存在恢复档。

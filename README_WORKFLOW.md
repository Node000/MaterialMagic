# 项目开发导航

本项目采用 BaseWorkflow 1.0.0 的按需阅读和方法复用原则，已按现有 Unity 工程独立适配；不要求用户审阅日常知识或项目 Skill 维护。

- 协作入口：`AGENTS.md`
- 项目现状：`Assets/Docs/Workflow/PROJECT.md`
- 架构地图：`Assets/Docs/Workflow/ARCHITECTURE.md`
- 模块知识：`Locus/knowledge/memory/unity-project-understanding/`
- 当前玩法：`Locus/knowledge/design/current-game.md`
- Skill 索引：`Locus/knowledge/skill/INDEX.md`
- 已知缺口：`Assets/Docs/Workflow/KNOWN_GAPS.md`
- 旧资料恢复档：`Assets/Docs/Archive/knowledge-before-rebuild-2026-11-05.zip`，非当前指令，不默认解压或读取。

不要建立第二套 docs/agent-skills 副本。项目知识纳入 Git，Locus 运行配置、会话与工作树继续忽略；不自动提交。新增/删除项目 Skill 同步索引即可，不安装到用户级目录。

未来修改时先更新对应现行说明；不复制源码中的完整数值表或每次生成全库哈希。无长期变化不制造日志。外部 BaseWorkflow 源副本不随本项目变化自动同步。

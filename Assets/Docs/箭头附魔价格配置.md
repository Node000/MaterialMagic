# 箭头附魔与商店价格配置

当前计算入口是ShopPanelUI.GetMaterialOfferPrice/GetMaterialEnchantPriceDelta：普通箭头用商品条目price（免费0有效，负数回退默认），附魔箭头用普通基价+Definition.price，再经DifficultyUpgradeSystem.ModifyShopPrice。当前EconomyConfig.shopMaterialPrice为2。

每个 `Assets/Resources/EnchantConfig/MaterialModifiers/<id>.asset` 的MaterialModifierDefinition.price是**价格差值**：正数更贵、负数更便宜、0不变。日常在Inspector改目标SO，结构化修改用Unity API；附魔商品条目的price不用于该附魔最终报价。不要把“所有附魔求和”写成当前单modifier报价路径。

改价不自动上架。ShopPanelUI.IsExcludedShopModifierId当前排除omni_arrow、return_arrow、period_arrow、pack_arrow、linked_arrow、random_arrow、eternal_arrow、repeat_arrow；只加入ShopProductPoolData不足以解除排除。奖励池标记、商店池与解锁也彼此独立。

道具价格按shopSpellPrice+稀有度偏移（Common -2、Rare -1、Epic0、Legendary+1），再走进阶；卖价买价一半向下取整。战后自动基础金币与“更多金币”选项是不同路径。细表从配置读取，不在多份文档维护易过期价格清单。

接入方法见 `Locus/knowledge/skill/content-integration/enchantments.md`；图标配置见 `Assets/Docs/Boss图标与附魔图标配置.md`。本轮未调价格或美术数据。

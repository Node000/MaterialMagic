# 箭头附魔价格配置说明

实现日期：2026-09-19

## 1. 价格模型

- **基础价**：无附魔普通箭头 = **2**（`Assets/Resources/Data/EconomyConfig.json` 的 `shopMaterialPrice`，以及 `ShopProductPoolData.json` 普通箭头条目的 `price`，两处当前都是 2）。
- **附魔箭头价** = 基础价 + 该箭头**全部附魔的 `price` 之和**，最后统一经 `DifficultyUpgradeSystem.ModifyShopPrice`（进阶加价/折扣）。
- 商店计算入口：`Assets/Scripts/ShopPanelUI.cs` 的 `GetMaterialOfferPrice()` / `GetMaterialEnchantPriceDelta()`。
- `ShopProductPoolData.json` 里**附魔条目自身的 `price` 不再被读取**（只有"无附魔"的普通项读它）。为避免误读，条目 `price` 已同步成实际售价，方便直接对照。

## 2. 附魔自己的 price 从哪来

- 每个附魔一份 ScriptableObject：`Assets/Resources/EnchantConfig/MaterialModifiers/<附魔id>.asset`（`MaterialModifierDefinition`）。
- Inspector 上的 **`price`（商店价格差值）** 就是该附魔对箭头价格的增减：
  - `0` = 不影响价格（箭头价 = 普通箭头价）；
  - 正数 = 更贵，负数 = 更便宜（弱附魔）。
- 运行时该值经 `MaterialModifierDatabase` 读进 `MaterialModifierData.price`，只影响商店箭头价格，不影响战斗表现。

## 4. 相关行为说明

- **多重箭头（双重/三重/四重）**：行为不变 —— 只触发一次基础效果，另外供应 N 个连续配方格；价格靠上面的 `price` 体现（3 / 5 / 6）。
- **暂不上架的附魔**：`omni_arrow` / `random_arrow` / `eternal_arrow` / `repeat_arrow` / `return_arrow` / `period_arrow` / `pack_arrow` / `linked_arrow` 目前被 `ShopPanelUI.IsExcludedShopModifierId()` 排除，不会进商店池；它们的 `price` 已按本表填好，将来若要上架只需把它们加进 `ShopProductPoolData.json` 的对应池，无需再调价格。
- **其它商店价格**（本次未变）：删箭头 2（`shopRemoveMaterialPrice`）、刷新 1 起（`shopRefreshPrice`，每次刷新 +1）；道具按稀有度：普通 3 / 稀有 4 / 史诗 5 / 传说 6（`shopSpellPrice` 5 + 稀有度偏移 Common -2、Rare -1、Epic 0、Legendary +1）；道具卖出价 = 购买价减半向下取整。
- **战斗金币**（本次未变）：弱怪池 1 / 普通池 2 / 强怪池 4 / 精英与 Boss 6（`EconomyConfig` 的 `weakBattleGold` / `battleGoldMin` / `strongBattleGold` / `eliteBattleGoldMin`），用于战斗结算"更多金币"选项；战斗结束自动到手的基础金币固定 2。开局金币 = 各开局配置（`StartConfig.json`）里的 `gold`，当前 4 个配置都是 2（教程局固定 10，走 `TutorialManagerUI.TutorialStartGold`，不受本表影响）。

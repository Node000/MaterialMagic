# 道具匹配与视觉顺序

当前排序先按箭头读取Token的匹配起点，同一起点按道具真实视觉顺序：从上到下、行内从左到右。没有视觉排名时回退SlotIndex；不按配方长度排序。重读序列和不同起点仍可能重复触发。

入口：`Assets/Scripts/MagicBookVisualOrder.cs`计算布局排名和拖拽落点，`Assets/Scripts/MagicMatchOrderUtility.cs`组织匹配结果，HandSystemUI.CollectCastableMagicsInLayoutOrder连接二者。PC弧形单行与PE网格都应从当前布局读取，而非为固定槽位数写死顺序。

已有 `Assets/Tests/Editor/MagicMatchOrderTests.cs`覆盖规则/布局/拖拽。修改相关逻辑后按影响选择一次测试或目标布局冒烟，具体方法见battle-rule-change Skill。历史15/15及PE坐标记录归档，本轮未重跑，不把旧通过当当前运行结果。

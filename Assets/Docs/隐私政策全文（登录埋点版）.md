温馨提示

欢迎游玩《有氧地下城》！我们会在游戏过程中收集一部分**游戏内数据**，用于内容开发与平衡性调整。为便于您快速了解，我们把关键内容整理成了一份 30 秒就能读完的摘要；完整条款见下文《有氧地下城隐私政策》。

一页读懂（30 秒版）

· 我们收集什么：你在游戏里怎么玩（打到哪一层、选了什么、在哪一关失败、玩了多久）、设备和运行信息（机型、系统版本、闪退记录）。
· 我们拿它做什么：内容开发、难度与数值平衡、问题定位。不做别的用途。
· 我们不做什么：不读通讯录 / 相册 / 位置 / 麦克风 / 摄像头；不要你的姓名、手机号、身份证号；不投广告，不卖给任何第三方，也不做广告画像。
· 谁能看到：只有《有氧地下城》的开发团队（K&Z 工作室），以及提供登录与数据统计服务的 TapSDK（TapTap，见第五条）。
· 不想分享怎么办：可以在首次提示中选择「不同意」，游戏与 TapTap 登录都不受影响；也可以随时在游戏内「设置 → 测试数据收集」里关闭。
· 数据怎么删：按本政策第十条的联系方式找我们即可。

请您阅读完整版《有氧地下城用户协议》及《有氧地下城隐私政策》了解详细信息。首次进入游戏时我们会询问是否允许「测试数据收集」，选择「同意」或「不同意」都可以正常游玩；由于登录与数据统计由同一套 SDK 提供，选择「不同意」时我们也不会使用 TapTap 登录服务。

我们不会主动申请开启您的任何设备权限。我们已采取符合业界标准的安全防护措施保护您的个人信息。

在您使用有氧地下城前，请您务必认真阅读本隐私政策，充分理解各条款内容，包括但不限于免除或限制我们责任的条款。您知晓并确认，您勾选“同意”本隐私政策并使用有氧地下城，就表示您同意我们按照本隐私政策处理您的个人信息。请您知悉，本政策仅适用于我们通过有氧地下城向您提供服务所收集的信息，不适用于通过接入有氧地下城以向您提供产品或服务的第三方所收集的信息。

一、我们如何收集和使用您的个人信息
（一）我们如何收集您的个人信息
在您使用有氧地下城过程中，我们会按照如下方式收集您的个人信息：
1.实名认证与防沉迷
根据国家有关未成年人保护与游戏防沉迷的规定，当您使用 TapTap 账号登录游戏时，相关实名认证与防沉迷要求由 TapTap（易玩（上海）网络科技有限公司）在其账号服务中执行。我们不自行收集您的姓名、身份证件类型和身份证件号码，也不保存上述信息。
如您未完成 TapTap 平台的实名认证，或处于防沉迷限制状态，可能无法登录游戏，或在游戏过程中受到游戏时长、功能方面的限制。

2.账号登录（TapTap 登录）
当您已同意「测试数据收集」时，游戏启动时我们会通过 TapTap 提供的登录服务自动尝试使用您的 TapTap 账号登录，并获取您的 TapTap 账号标识（OpenID、UnionID）；我们不会获取您的昵称、头像。我们收集这些信息，是为了识别您的账号身份。在授权界面您可以取消登录；取消后您可以游客身份继续游玩，游戏内容不受影响，此时我们不会获取您的 TapTap 账号信息。
如果您选择「不同意」或之后关闭了「测试数据收集」，由于登录由同一套 SDK 提供，我们不会初始化登录服务、也不会尝试为您登录，您仍可正常游玩（存档保存在本机）。关闭后的当前会话只停止测试数据的收集与上报，不会结束您已有的登录状态；从下次启动起登录服务才一并停用，重新开启后会再次启用。

3.测试数据收集（可在设置界面关闭）
为持续改进游戏体验、调整关卡与数值难度、定位并修复问题，我们会收集您在游戏过程中的决策数据，以及为完成统计所必需的设备信息，用于后续游戏开发与完善：
(1)决策数据：关卡进度与对局结果、对局时长、战斗与事件中的选择、道具与资源的获取及消耗、金币与生命值变化、登录与页面操作记录等；
(2)设备信息：系统版本、设备型号、设备 CPU 信息、设备内存信息、网络类型、Android ID 等设备标识信息；
(3)统计服务生成的匿名标识：用于区分不同设备的数据，不包含您的姓名、手机号、身份证件号码等身份信息。
上述信息仅用于本政策「一（三）」载明的目的。除本政策第五条所列的第三方 SDK 外，我们不会将上述信息提供给其他第三方，也不会将其用于广告投放。
如果您不想分享这些数据，也完全不影响游玩：在首次提示中选择「不同意」即可，只是我们收不到这些数据，也不会因此为您登录 TapTap 账号。这些数据只用于上面说的目的，绝不会用于广告，也不会出售或提供给任何第三方。您可以随时在游戏内「设置 → 测试数据收集」里关闭或重新开启这一功能。


（一）附：我们不会做什么（把边界讲清楚）
为了避免任何误解，我们在这里把“不做什么”一次讲清楚。以下事情我们不会做：
1.不收集您的通讯录、相册、位置、麦克风、摄像头、短信、通话记录等与游戏无关的信息，也不主动申请这些设备权限；
2.不收集您的姓名、手机号、身份证件号码、银行卡号等身份信息（实名认证与防沉迷由 TapTap 平台账号服务执行，见上文 1）；
3.不出售、不出租您的任何数据，不向广告商或数据商提供，不使用您的数据做广告投放或广告画像；
4.不把您的数据用于与游戏无关的用途，也不用它来单独识别“您这个人”。
只有《有氧地下城》的开发团队（K&Z 工作室），以及提供登录与数据统计服务的 TapSDK（TapTap，见第五条）能接触这些数据。

（二）设备权限调用情况
在您使用有氧地下城过程中，我们不会主动向您申请获取设备权限。为向您提供账号登录与数据统计服务，游戏需要访问网络，因此会在安装包中声明网络访问权限（Android：INTERNET 权限）。该权限在安装时由系统提示，不需要您手动授权；我们不会读取您的通讯录、相册、位置、麦克风、摄像头等信息。

（三）我们如何使用您的个人信息
1.我们会根据本政策的约定并为实现我们的服务的目的对所收集的个人信息进行使用。 
2.请您注意，您在使用我们提供的服务时所提供的所有个人信息，除非您删除或通过系统设置拒绝我们收集，否则将在您使用我们的服务期间持续授权我们使用。在您注销账号时，我们将停止使用并删除您的个人信息。
3.我们会对我们提供的服务使用情况进行统计，并可能会与公众或第三方共享这些统计信息，以用于产品开发、服务优化、安全保障的目的。但这些统计信息不包含您的任何身份识别信息。 
4.当我们要将您的个人信息用于本政策未载明的其它用途时，或基于特定目的收集而来的信息用于其他目的时，会通过您主动做出勾选的形式事先征求您的同意。 

（四）其他规则
根据相关法律法规及国家标准，以下情形中，我们可能会收集、使用您的相关个人信息而无需征求您的授权同意：
(1)与我们履行法律法规规定的义务相关的；
(2)与国家安全、国防安全直接相关的；
(3)与公共安全、公共卫生、重大公共利益直接相关的；
(4)与刑事侦查、起诉、审批和判决执行等直接相关的；
(5)出于维护个人信息主体或其他个人的生命、财产等重大合法权益但又很难得到本人授权同意的；
(6)所涉及的个人信息是个人信息主体或监护人自行向社会公众公开的；
(7)根据个人信息主体要求签订和履行合同所必需的；
(8)从合法公开披露的信息中收集个人信息的，如合法的新闻报道、政府信息公开等渠道；
(9)维护所提供产品或服务的安全稳定运行所必需的，如发现、处置产品或服务的故障。

二、我们如何保存您的个人信息
1.我们将在本政策载明的目的所需及法律法规要求的最短保存期限之内，保存您的个人信息。前述期限届满后，我们将对您的个人信息做删除或匿名化处理。
2.我们在中国境内运营过程中收集和产生的个人信息将保存在中国境内（为本隐私政策之目的，“中国境内”不含中国港澳台地区），以下情形除外：
(1)法律有明确规定；
(2)获得您的明确授权；
(3)您要求获取境外服务等个人主动行为。
针对以上情形，我们会确保依据本隐私政策以及相关法律规定对您的个人信息提供足够的保护。
3.您的游戏存档、游戏设置以及数据统计服务所需的匿名标识文件保存在您设备的应用私有目录中。您可以使用游戏内的「删除存档」功能清除本地存档数据，卸载应用也会清除本地保存的上述文件。
4.如果在某次启动中暂时无法完成上报（例如您在首次提示里选择了同意、而本次启动尚未开放采集），待上报的事件会先暂存在同一目录下的文件中，并在下次启动游戏时自动补报；撤回同意、关闭开关或删除存档时，这些暂存数据会被一并删除。

2.删除您的个人信息 
在以下情形中，您可以通过本隐私政策载明的方式向我们提出删除个人信息的请求：
(1)我们违反法律、行政法规或与您的约定收集、使用个人信息；
(2)我们违反法律、行政法规或与您的约定与第三方共享或转让您的个人信息，我们将立即停止共享、转让行为，并通知第三方及时删除；
(3)我们违反法律、行政法规规定或与您的约定，公开披露您的个人信息，我们将立即停止公开披露的行为，并发布通知要求相关接收方删除相应的信息；
(4)您不再使用我们的产品或服务，或您注销了账号，或我们终止服务及运营。
(5)您希望删除我们通过数据统计服务收集的数据时，可以通过本政策载明的方式与我们联系，我们将在核实您的身份后处理您的请求，包括向 TapTap 申请删除相应统计数据。
3.改变您授权同意的范围
您可以通过设备权限设置或本隐私政策载明的方式与我们联系，以改变同意范围或撤回您的授权。
请您理解，有氧地下城可能需要开启部分权限并收集必要的个人信息才能得以实现。当您撤回您的同意时，我们将无法继续为您提供撤回同意所对应的服务，但不会影响此前基于您的授权而开展的个人信息处理服务。
您可以随时通过本政策载明的方式与我们联系，撤回对游戏数据统计的同意；我们将在核实后停止相应的数据收集，并删除或匿名化处理已收集的相关数据。撤回同意不影响此前基于您的授权已开展的个人信息处理。
你也可以随时在游戏内的「设置 → 测试数据收集」里改变主意：打开它，我们自己的数据上报会立即恢复；如果本次启动时统计服务是按“不收集”启动的（例如你刚在首次提示里选了同意），这些数据会先暂存在你设备的应用私有目录里，并在下次启动游戏时自动补报，因此不会丢失（补报的数据会带一个“补发”标记）。关闭它，我们自己的数据上报会立即停止，并删除尚未上报的本地暂存数据；由于统计服务（TapSDK）的采集开关在启动时就已确定、不提供运行期间单独关闭的接口，本次已经启动的游戏里由它自身产生的启动与时长记录可能仍会发送，下次启动就不会再有了。无论开关如何变化，TapTap 登录都不受影响。

5.响应您的上述请求
如您无法按照上述方式行使权利的，您可以采取本隐私政策载明的联系方式与我们联系。为保障安全，您可能需要提供书面请求，或以其他方式证明您的身份。我们可能会先要求您验证自己的身份，然后再处理您的请求。

6.响应情形的例外

(1)与我们履行法律法规规定的义务相关的;
(2)与国家安全、国防安全直接相关的;

(4)与刑事侦查、起诉、审判和执行判决等直接相关的; 
(5)我们有充分证据表明个人信息主体存在主观恶意或滥用权利的;
(6)出于维护个人信息主体或其他个人的生命、财产等重大合法权益但又很难得到本人同意的;
(7)响应个人信息主体的请求将导致个人信息主体或其他个人、组织的合法权益受到严重损害的;
(8)涉及商业秘密的。

# 埋点登记与后台维护入口

本地规范文件：`Assets/Docs/event.csv`（事件与属性绑定）、eventProp.csv（属性名/类型/事件绑定）、userProp.csv（设备属性）。CSV保留实际登记数据，本轮未重写其内容，也未同步后台。数量以文件为准，不维护另一份手抄清单。

代码来源为 `Assets/Scripts/Analytics/AnalyticsEvent.cs`、AnalyticsProperty.cs、RunAnalyticsLedger.Context以及HandSystemUI.Emit*等调用；AnalyticsService.BuildPayload自动补is_dev，不代表自动补全所有上下文。自定义名称/类型与SDK实际归一化行为要一起看，不能仅按CSV猜最终payload。

已接入游戏调用，旧“P0-B待做”失效；定义存在、调用可达、后台入库分别验证。一个属性同名应保持类型，属性还须与目标事件关联；CSV表头/绑定分隔格式沿现有文件，不改成Markdown或YAML。

发生缺字段时按顺序定位：同意和SDK就绪→实际Emit是否执行→当前payload字段/类型→元数据事件绑定→实时明细/概览与一次字段查询。过去错误详情与真实入库曾不一致，单条错误详情不证明全部字段丢失。不要靠正则跨方法推断每个事件完整字段，读实际组装入口。

后台写入、上传CSV、开实时监测或发测试事件需要对应任务授权；本次没有访问后台，不证明本地三表已与线上一致。凭据、设备/账号原始标识和本地日志不复制进知识。报表参考 `Assets/Docs/TapDB数据分析配置清单.md`，平台开关边界见platform模块。

# 正式开发入口

本目录已从审阅草案改为正式导航，按当前Unity工程独立适配BaseWorkflow 1.0.0。

1. [PROJECT](PROJECT.md)：环境、入口、数据来源与验证边界。
2. [ARCHITECTURE](ARCHITECTURE.md)：受影响模块、工厂差异与HandSystemUI符号。
3. [项目Skill](../../../Locus/knowledge/skill/INDEX.md)：按任务加载方法及内容附页。
4. [KNOWN_GAPS](KNOWN_GAPS.md)：未接入功能与有证据的限制。
5. [重建结果](REBUILD_RESULT.md)：改动范围、恢复档与本轮验证。

用户已授权自主维护项目知识和项目Skill，不安排逐项审阅；新玩法、外部操作和美术调参仍遵守任务范围。先集中改一批，再一次最低成本收尾，不默认跑Unity全套、不反复哈希。原BaseWorkflow目录不随本项目自动同步。

人类文档索引见 [Assets/Docs/INDEX.md](../INDEX.md)，根入口是 `AGENTS.md` 与 `README_WORKFLOW.md`。不新增docs/agent-skills副本，不把历史恢复档解压回活动知识。

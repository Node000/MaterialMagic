# 事件本地化文本审阅（zh-CN）

- 用途：统一审阅 / 润色全部事件文本。**「文本」列直接改**，`event.*` 键名保持不动；改完回写 `Assets/Resources/Data/Localization/zh-CN_Event.json`。
- 本文件位置：`Assets/Docs/事件本地化文本审阅.md`（后续所有事件文本调整以本文件为准）。
- 数据来源：`Assets/Resources/Data/EventData.json`（结构、配方、效果）+ `Assets/Resources/Data/Localization/zh-CN_Event.json`（文本）。本文件按当前数据生成，数据改动后需重新生成。
- 「效果」列同样是可改的：数值改动同步到 `EventData.json`；措辞改动同步到 `zh-CN_UI.json`（工具 tip 文案模板）与 `Assets/Scripts/UnifiedDetailContentBuilder.cs` 的默认文案。
- 同一 key 被两个按钮复用时要写不同文案，需先在 `EventData.json` 拆出独立 key（例：`event.promo_link.option.stop` / `stop_again`）。
- 配方字符映射：`1`=上(火)　`2`=左(风)　`3`=下(水)　`4`=右(土)；【乱序N张】= `randomRecipeLength=N` + `ignoreOrder`。
- 抽牌数：进入事件时抽多少张事件手牌；`-1` 表示跟随玩家当前抽牌数。
- 英文（`en-US_Event.json`）已按文末「英文对照清单」全部补齐（116–123 新增事件的 72 个 key 已翻译写入）；后续中英不同步时以本文件为基准同步两份 JSON。

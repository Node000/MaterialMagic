# 敌人意图与状态图标接入说明

意图图片位于 `Assets/Resources/Images/Intent/`，EnemyIntentData.displayType按现有加载规则指定；Buff图片位于Images/Buffs，通过BuffIconData.json的iconName绑定。透明PNG需在Unity导入为Sprite，沿用现有128×128交付口径与缩小后的识别性。

当前需要哪个专属图标，应从最终敌人Definition、具体敌人GetSpecialIntentDisplayValue/Tooltip、EnemyIntentView和现有图片查证；旧逐敌人数值/缺图清单已在恢复档，不再当未完成工单。修改普通图标不自动覆盖特殊意图分支。

预览值必须来自同一实际规则，不推进意图、不抽第二次随机、不触发伤害。专属名称/说明同步中英Enemy或对应本地化表，Buff名称/描述/图标走独立映射。美术颜色与显示尺寸保留Scene/Prefab设置，代码不硬编码重写。

新增敌人方法见 `Locus/knowledge/skill/content-integration/enemies.md`；具体素材增补只在获得本次任务授权后执行。本轮未新增图像或改导入器。

# 《有氧地下城隐私政策》埋点相关条款修改稿（审阅用 v2）

状态：**已评审采纳**（2026-09-30 用户回复「均采纳」）；全文版已合成：`Assets/Docs/隐私政策全文（登录埋点版）.md`（可直接替换腾讯文档）。

> **v3 变更（2026-09-30）**：登录流程改为**游戏启动时自动登录、玩家可在授权界面取消、取消后以游客身份继续游玩**，且只请求 `basic_info`（不收集昵称/头像）。因此「账号登录」条款与第五条 SDK 表已同步改写，**以《全文版》为准**。v2 已按 2026-09-30 决定更新（**防沉迷由 TapTap 平台自动接入**；**数据统计必定进行、不提供关闭按钮**）
起因：接入 **TapTap 登录**（新增）与 **TapDB 数据统计**（新增埋点）后，原政策「一（一）」只写了实名认证、「五、第三方产品或服务」写着“我们不会使用下述第三方 SDK”，均与实际不符。
写法说明：本文**只给需要替换/新增的段落**，其余条款照旧；每段都可整段复制。措辞按“对用户说话”的口径写成，避免技术名词堆叠。

## 二、逐段修改稿

### 修改 1：一（一）1.实名认证（整条替换）

```
1.实名认证与防沉迷
根据国家有关未成年人保护与游戏防沉迷的规定，当您使用 TapTap 账号登录游戏时，相关实名认证
与防沉迷要求由 TapTap（易玩（上海）网络科技有限公司）在其账号服务中执行。我们不自行收集
您的姓名、身份证件类型和身份证件号码，也不保存上述信息。
如您未完成 TapTap 平台的实名认证，或处于防沉迷限制状态，可能无法登录游戏，或在游戏过程中
受到游戏时长、功能方面的限制。
```

> 说明：TapTap 平台会自动接入防沉迷，因此原政策里“我们收集姓名/证件号”的表述与本项目实际不符，改用平台口径更准确。

### 修改 2：一（一）新增两条（接在「1.实名认证与防沉迷」之后）

```
2.账号登录（TapTap 登录）
游戏启动时，我们会通过 TapTap 提供的登录服务自动尝试使用您的 TapTap 账号登录，并获取您的
TapTap 账号标识（OpenID、UnionID）；我们不会获取您的昵称、头像。我们收集这些信息，是为了
识别您的账号身份、为您提供与账号相关的功能。在授权界面您可以取消登录；取消后您可以游客身份
继续游玩，游戏内容不受影响，此时我们不会获取您的 TapTap 账号信息。

3.游戏数据统计与分析
为持续改进游戏体验、调整关卡与数值难度、定位并修复问题，我们会收集您在游戏过程中的决策
数据，以及为完成统计所必需的设备信息，用于后续游戏开发与完善：
(1)决策数据：关卡进度与对局结果、对局时长、战斗与事件中的选择、道具与资源的获取及消耗、
   金币与生命值变化、登录与页面操作记录等；
(2)设备信息：系统版本、设备型号、设备 CPU 信息、设备内存信息、网络类型、Android ID 等
   设备标识信息；
(3)统计服务生成的匿名标识：用于区分不同设备的数据，不包含您的姓名、手机号、身份证件号码
   等身份信息。
上述信息仅用于本政策「一（三）」载明的目的。除本政策第五条所列的第三方 SDK 外，我们不会将
上述信息提供给其他第三方，也不会将其用于广告投放。
数据统计是我们改进游戏所必需的功能；如您不同意本政策，请不要点击「同意」并停止使用本服务。
```

### 修改 3：一（二）设备权限调用情况（整段替换）

```
（二）设备权限调用情况
在您使用有氧地下城过程中，我们不会主动向您申请获取设备权限。为向您提供账号登录与数据
统计服务，游戏需要访问网络，因此会在安装包中声明网络访问权限（Android：INTERNET 权限）。
该权限在安装时由系统提示，不需要您手动授权；我们不会读取您的通讯录、相册、位置、麦克风、
摄像头等信息。
```

### 修改 4：五、第三方产品或服务如何获得您的个人信息（整节替换）

```
五、第三方产品或服务如何获得您的个人信息
为向您提供账号登录与游戏数据统计服务，我们会使用第三方软件开发工具包（SDK）。我们已对
以下 SDK 进行安全评估，并要求其按照本政策及法律法规处理您的个人信息：

| SDK 名称 | 提供方 | 使用目的 | 收集的信息 | 收集时机 | 隐私政策 |
| --- | --- | --- | --- | --- | --- |
| TapSDK（TapTap 登录） | 易玩（上海）网络科技有限公司 | 启动时自动登录 TapTap 账号，并落实实名认证与防沉迷要求 | TapTap 账号标识（OpenID、UnionID）、实名认证与防沉迷状态 | 游戏启动时自动发起（您可在授权界面取消） | https://www.taptap.cn/doc/privacy-policy/ |
| TapSDK（数据统计 / TapDB） | 易玩（上海）网络科技有限公司 | 统计游戏内决策数据，用于游戏开发与体验完善、难度与数值调整、问题定位 | 系统版本、设备型号、设备 CPU 信息、设备内存信息、网络类型、Android ID，以及游戏内决策数据（关卡进度、对局时长、战斗与事件选择、道具获取与消耗等） | 您同意本政策后，在游戏过程中 | https://www.taptap.cn/doc/privacy-policy/ |

自动登录过程中您可以取消授权，此后以游客身份游玩，我们不会通过登录服务获取您的 TapTap
账号信息，仅涉及上表所列的游戏数据统计。如您希望撤回同意或删除统计数据，可通过本政策第十条
载明的方式与我们联系。
```

### 建议 7：四（共享）1.委托处理

原句为“…基础设施技术、数据分析、广告投放、营销决策等产品或技术支持”。目前我们没有广告投放、营销决策类的合作方，建议改成：

```
我们会委托第三方服务提供商处理我们所收集的您的个人信息，以便其为我们提供基础设施技术、
数据分析等产品或技术支持（当前为 TapSDK 的登录与数据统计服务，详见本政策第五条）。上述
委托处理行为受本政策中所声明目的约束，并且我们会以合同的方式对上述受托的第三方服务
提供商进行监督。
```

## 三、已确认事项与遗留观察项

已采纳（2026-09-30）：

1. **防沉迷条款的措辞**：按“TapTap 平台执行实名与防沉迷、我们不自行收集姓名/证件号”定稿。若 TapTap 后台后续要求游戏内展示实名/防沉迷说明、投诉渠道或时长限制提示，再把要求给我补条款。
2. **修改稿的采纳范围**：网络权限说明、Cookies 章节补说明、四（共享）删去“广告投放、营销决策”全部采纳，已落入全文版。
3. **政策主体与联系方式**：沿用原文（K&Z工作室、地址、电话），未新增客服邮箱。

遗留观察项（不影响发布）：

- **撤回通道的形式**：按决定，游戏内**不提供**关闭数据统计的开关，因此“撤回同意/删除数据”只能走政策第十条的**联系方式**。需留意发行/应用商店审核是否要求“可直接操作的撤回入口”；若被要求，最小改动是在设置里加「隐私设置 → 撤回数据统计同意」（撤回后停止上报并清空本地待发队列），可后续补丁。

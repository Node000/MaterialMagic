# 角色位于相邻两层画框之间

已确认的空间关系：观察者 → 外层框 A → 角色 → 内层框 B。

角色超出 A 的部分被裁剪；角色可以覆盖 B 的画面和边缘。A 负责裁剪，B 在角色后方。角色在 B 的矩形内部仍然可以显示。

本版本使用正常的 RectMask2D 和 UI 绘制顺序。不要再给角色挂上一版 UIInverseRectClip 或反向裁剪材质；本包只需要 MirrorHallLayers.cs。

## 先验证一组框

在同一个 Canvas 中创建：

```text
A：RectTransform + RectMask2D
├─ Background：背景，可选
├─ B：RawImage，缩小的内层画面
├─ Subject：Image，角色
└─ Frame：A 的边框，中间透明
```

Subject 和 B 是同级，Subject 排在 B 后面绘制。不要把 Subject 放进 B 的裁剪节点。先保持这些对象共面，不添加独立 Canvas 或 Override Sorting。

以 A = 1000 × 600、所有锚点和轴心居中为例：

- B 的尺寸 = 720 × 432，位置 = (0, 0)。
- Subject 的尺寸 = 160 × 372，位置 = (360, 0)。角色可以盖住 B 的右边缘。
- 将 Subject 移到 (500, 0)，角色超出 A 右边界的部分消失。

## 多层结构

脚本逐层嵌套以下结构，内层的整个子树先绘制，再绘制本层角色和边框：

```text
A：RectMask2D
├─ Background A
├─ B：RectMask2D
│  ├─ Background B
│  ├─ C：RectMask2D
│  │  └─ ……
│  ├─ Subject B：覆盖 C，由 B 裁剪
│  └─ Frame B
├─ Subject A：覆盖 B，由 A 裁剪
└─ Frame A
```

更近的角色也会正常遮挡更远的角色。

## 准备源画面

1. 停用原先 InfiniteUIWindow 的整屏截图循环及旧 Preview。
2. 在 Project 中创建 Render Texture，命名 SceneOnly，先设置为 1280 × 720。Game 视图也设为 16:9。
3. 将渲染 2D 场景的摄像机的 Target Texture / Output Texture 设为 SceneOnly，背景颜色保持不透明。本脚本不手动调用 Camera.Render。
4. 源画面中排除绿色主体和最终展示 Canvas。原主体若为 SpriteRenderer，可关闭该 Renderer 或通过源摄像机的 Culling Mask 排除它的 Layer。
5. 如有需要一起复制的其他 UI，放入单独的 Screen Space - Camera Canvas，Render Camera 指向源摄像机。

摄像机写入 RenderTexture 后，场景通过脚本生成的 RawImage 显示。最终展示使用 Screen Space - Overlay Canvas，避免再次进入源摄像机的画面。

## 使用脚本

1. 用本包的 MirrorHallLayers.cs 替换旧的同名脚本，只保留一个同名类。
2. 创建 Screen Space - Overlay Canvas；Canvas Scaler 可设置 Scale With Screen Size，参考尺寸 1280 × 720。
3. 在 Canvas 下创建 HallRoot。它的 RectTransform 就是最外层入口 A，可设为全屏拉伸，也可设为一个较小的窗口。
4. 将 MirrorHallLayers 挂到 HallRoot，Scene Texture 拖入 SceneOnly，Subject Sprite 拖入角色的透明背景 Sprite。
5. 若沿用旧组件，手动设 Shrink = 0.72、Subject Position = (0.36, 0)、Subject Size = (0.16, 0.62)。Unity 会保留旧的序列化字段值，替换代码不会自动更新这些数值。
6. 不要给生成内容添加 Layout Group 或独立的 Override Sorting Canvas。运行后层级自动建立。

如果运行后才补齐源贴图和 Sprite，重新启用组件或使用右键菜单 Rebuild Layers。

## 参数

- Layer Count：角色所在的间隔数量，默认 20；额外生成一张最深处的终止画面。
- Shrink：内框相对外框的尺寸比例，默认 0.72。
- Subject Position：相对于本层外框 A 的宽高，从中心计算。X = 0.36 是默认内框 B 的右边缘；X = 0.5 是 A 的右边缘。
- Subject Size：角色尺寸相对于本层外框 A 的宽高，Image 保留 Sprite 宽高比。
- Offset Per Step：内框相对外框的平移；更深层按缩放比例递减。
- Frame Color / Frame Thickness：边框颜色和厚度。厚度设为 0 可隐藏边框。

运行时修改 Layer Count 后重新启用组件或使用 Rebuild Layers。其余布局参数逐帧更新。动画控制器可调用 SetSubjectSprite(sprite)，使所有副本同步换帧。

## 验证范围与限制

本版本是共面 UGUI 的空间遮挡模拟，使用常规 RectMask2D。绘制顺序由嵌套层级控制。

各层共用同一个干净的实时源画面，默认不包含 OBS 式逐层一帧延迟；若需保留延迟，还要保存源画面与角色状态的历史帧。

提供的是脚本和搭建说明，并非完整 Unity 工程。C# 尚未在用户项目中编译运行，需要导入后验证。
